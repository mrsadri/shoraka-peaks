# قله‌های شرکا — Commission landing page

Static single-page site (RTL, Persian) deployed with GitHub Pages.

- `index.html` — the whole page (HTML + CSS + JS inline)
- `fonts/` — DanaVF (variable) and Vazirmatn fallback
- `.nojekyll` — serve files as-is, no Jekyll build

To update: edit `index.html`, commit, push to `main`. Pages redeploys automatically.
